# Deadlands Classic RU v0.7.0 — тестовая сборка

- 75+ предметов, 8 авторских особенностей, народ «Человек» как ancestry Item.
- Три отдельных world Compendium: оружие/снаряжение, особенности, народы. Создание/обновление через кнопку «Создать библиотеку Deadlands RU».
- Добавлены ориентировочные боевые поля SWADE для 6 базовых видов оружия; значения **авторские и требуют сверки с книгой**.
- Кнопка «⭐ Повышения Deadlands» во вкладке Актёров: показывает ранг, полученные и запланированные повышения, позволяет Маршалу добавить запись в нативный system.advances.list.
- Физические SVG в assets/icons и fallback на системную иконку при ошибке загрузки.
- Старый смешанный world Compendium не удаляется автоматически; после проверки можно удалить его вручную.
- Автоматического изменения навыков/черт при выдаче повышения нет; Маршал меняет параметры в листе SWADE.
- Модуль проверен статически, не тестировался в запущенном Foundry/The Forge.
- ВАЖНО: исходная карточная генерация и авторские предметы могут не соответствовать конкретной редакции Deadlands.
