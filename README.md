# Deadlands Classic RU v0.6.0 — экспериментальная сборка

- 30 авторских предметов с ориентировочными ценами/весом и описаниями; 8 авторских особенностей. **Не являются официальными данными книг**.
- Собственные SVG-иконки в assets/icons.
- Кнопка «Создать библиотеку Deadlands RU» в шагах каталога создаёт world Compendium `world.deadlands-ru-library` и заполняет его Item. Требуются права GM. Повторный запуск не дублирует записи по ключу.
- Для доступа из консоли GM: `game.deadlandsClassicRU.installLibrary()`.
- Поле «Народ» хранится в flags модуля, **пока не создаёт ancestry Item**.
- Действия/урон и автоматические эффекты не назначаются без проверки совместимости с SWADE 5.2.6.
- Для публикации в GitHub использовать исходный ZIP как релиз v0.6.0, обновив module.json в main.
- Созданные Compendium в мире Foundry нужно резервировать отдельно: они не входят в архив модуля.
