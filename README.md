# Deadlands Classic RU v0.2.1 — тестовая сборка

Исправлена отсутствовавшая функция `skillBreakdown` (шаг навыков падал при открытии), добавлен сброс характеристик при повторной раздаче/сбросе карты. Взяты интерфейсные улучшения из 0.2.0: занятые карты, пояснение стоимости навыков, вертикальный скролл.

При создании навыка модуль теперь старается использовать существующий шаблон предмета SWADE вместо неполной структуры; если шаблона нет, навык пропускается с предупреждением. Это уменьшает риск повреждения листа, но совместимость не проверена в работающем Foundry. Не создавайте тестовых персонажей поверх важных игровых данных.

Полные собственные каталоги черт, изъянов и снаряжения из книг **ещё не реализованы**.

Установка: загрузить содержимое каталога в корень репозитория, создать GitHub release с тегом `v0.2.1` и прикрепить ZIP `deadlands-classic-ru-v0.2.1.zip`. ZIP должен содержать `module.json` в корне.
