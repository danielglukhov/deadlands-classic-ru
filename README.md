# Deadlands Classic RU — Character Builder (0.1.0)

**Ранний тестовый прототип, НЕ полная сборка правил.** Foundry VTT 13 + система SWADE 5.2.6.

## Уже реализовано
- Пошаговый мастер: герой → 7 карт → 5 характеристик + пункты навыков → навыки → выбор элементов из доступных Item Compendiums → итог.
- Правила карточной генерации Deadlands Reloaded (рус. «Мёртвые земли», с. 36): 54 карты, нельзя сбрасывать двойки и джокеров, таблица значений.
- Бюджет навыков, базовая проверка стоимости повышения.
- Создание Actor и сохранение выбора карт в flags.deadlands-classic-ru.
- Импорт выбранных предметов из доступных справочников.

## Пока НЕ реализовано
- Полный каталог черт/изъянов/оружия из трёх книг; книги не содержат всех базовых правил «Дневника авантюриста».
- Автоматическая проверка требований черт, изъянов и покупок; адаптация всех механик старой редакции к SWADE.
- Полная синхронизация всех особенностей листа и предметов с системой SWADE. Требуется проверка на живом мире.
- Отдельная русификация интерфейса SWADE.

## Локальная установка на The Forge
1. Сохраните резервную копию мира.
2. В Forge Assets Library загрузите содержимое папки модуля, если ваш тариф/интерфейс позволяет размещать custom modules. Иначе используйте поддерживаемую Forge установку пользовательских пакетов.
3. Включите `Deadlands Classic RU — Character Builder` в настройках модулей мира SWADE.
4. В каталоге «Актёры» нажмите `🤠 Создать героя Deadlands`. Если кнопка не появилась, выполните в консоли браузера `game.deadlandsClassicRU.open()`.

## Установка ПО МАНИФЕСТУ (нужен реальный URL)
The Forge / Foundry должны скачать `module.json` по публичному HTTPS URL. Локальный ZIP сам по себе **не является URL манифеста**.

1. Создайте GitHub-репозиторий `deadlands-classic-ru` (публичный, если хотите устанавливать через обычный raw.githubusercontent.com URL; НЕ публикуйте туда текст книг).
2. Замените `REPLACE_OWNER` в `module.json` на имя владельца GitHub.
3. Загрузите содержимое этой папки в корень репозитория и запушьте.
4. Создайте GitHub Release с тегом `v0.1.0`, приложите `deadlands-classic-ru.zip` (ZIP должен содержать папку `deadlands-classic-ru/`).
5. Установите по адресу `https://raw.githubusercontent.com/ВАШ_АККАУНТ/deadlands-classic-ru/main/module.json` через установку модуля по Manifest URL в The Forge.
6. При обновлении меняйте `version` и публикуйте новый release. URL в module.json должен быть действительным, иначе установка не сработает.

### Важно
В GitHub Actions присутствует workflow для автоматической сборки ZIP в релизах по тегам `v*`. Это избавляет от ручного прикрепления ZIP, если включены права workflow на запись.

## Проверка
В тестовом мире проверьте создание Actor, кубики характеристик, навыки, импорт предметов, закрытие и повторное открытие листа. Версия 0.1.0 — тестовый MVP, а не проверенный production-модуль.
