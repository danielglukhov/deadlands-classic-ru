# Deadlands Classic RU v0.3.0 — интеграционный тест

Исправлено создание Actor под SWADE 5.2.6 / Foundry 13: атрибуты пишутся по полным ключам после создания; деньги, архетип и биография записываются в стандартные поля; навыки сопоставляются по swid и создаются без клонирования Атлетики.

Ограничения: правила карт и стоимости навыков пока не сверены полностью с книгами; собственные каталоги Deadlands и автоматизация черт/изъянов не готовы. Требуется ручной тест в Foundry, особенно проверки листа, бросков, core skills и предметов.

Установка: загрузить файлы в корень GitHub репозитория, создать релиз с тегом v0.3.0 и прикрепить архив deadlands-classic-ru-v0.3.0.zip. Не обновлять SWADE до 6.x на Foundry 13.

## v0.4.0 (тестовая сборка)

- Поля внешности, целей и заметок передаются в штатные поля SWADE 5.2.6.
- Объединённый каталог читает видимые Item Compendium Packs и предметы мира.
- Каталог поддерживает черты, изъяны, оружие, броню, щиты, снаряжение и расходники.
- Отображаются доступные из индекса цены, вес, источник и краткое описание.
- Выбранные предметы импортируются по UUID, деньги уменьшаются на известную стоимость.
- Если цена не указана в источнике, она не выдумывается и не учитывается в расчёте.
- Автоматическая проверка требований черт и лимитов изъянов не реализована.
- Полный собственный каталог Deadlands ещё не включён; для него требуются проверенные данные.
- Штатные повышения и действия остаются под управлением SWADE.


## v0.5.0 (экспериментальная сборка)
- Отдельные шаги: черты, изъяны, особенности, снаряжение.
- Сохранение позиции прокрутки основного окна и списка при перерисовке.
- Каталог поддерживает Item типа ability.
- 20 **черновых** предметов Дикого Запада без подтверждённых цен и игровых параметров. Требуют ручного заполнения по книгам; НЕ являются готовым достоверным каталогом.
- Данные и цены из существующих доступных справочников SWADE сохраняются при импорте.
- Не реализовано: полные сверенные по книгам справочники, требования, автоматизация эффектов и комплекты.
